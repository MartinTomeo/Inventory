### Programación Web 1

### 17/09/2026

---

Aplicación web **Full Stack** desarrollada para la gestión de inventario de dispositivos, usuarios y asignaciones de equipos.

## Características

* Autenticación mediante **JWT** y refresh token.
* Control de acceso según roles y permisos.
* Gestión CRUD de **usuarios**.
* Gestión CRUD de **stock de dispositivos**.
* Carga, actualización y eliminación de imágenes de usuarios y equipos.
* Gestión de asignaciones entre usuarios y dispositivos mediante suscripciones.
* Prevención de asignaciones duplicadas.
* Eliminación individual y múltiple de suscripciones.
* Perfil de usuario con información personal y equipos asignados.
* Formularios reactivos con validaciones.
* Búsqueda y filtrado de información.
* Manejo de errores HTTP y notificaciones visuales.
* API REST protegida mediante autenticación y autorización.
